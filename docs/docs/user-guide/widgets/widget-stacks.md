# Widget stacks

A stack puts several widgets in one shared frame. Built-in widgets and widgets
provided by apps can be combined.

1. Open **Edit widgets** and place two widgets next to each other in the editing list.
2. On the first widget, choose **Stack with next widget**.
3. Open the stack's settings to add widgets, reorder pages or adjust the frame height.

To include the following widget in an existing stack, choose **Add next widget to
stack**. Stacks cannot contain other stacks.

Swipe horizontally or use the arrows beneath the frame to switch pages. Pages stay
the same height and never rotate automatically. Taller content can scroll inside
the frame. If a widget uses horizontal gestures itself, use the arrows to switch
pages.

The stack editor lets you configure individual widgets or remove them with Undo.
**Separate widgets** returns every page to the widget list in its current order.
Moving widgets into or out of a stack keeps their app-widget bindings and settings.
